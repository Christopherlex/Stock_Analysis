# Stock Search, Analysis, and Portfolio Optimization 📈

## Overview
This project provides tools for stock search, analysis, portfolio optimization, and backtesting. Users can search for stock data, visualize trends, optimize their portfolio based on risk-return profiles, and test trading strategies using technical indicators.

## Features 🚀

### Stock Search and Analysis
1. **Input Ticker**: Enter the stock ticker (e.g., BBCA for Bank Central Asia).
2. **Select Time Range**: Choose from predefined time periods (e.g., 1 Year, 6 Months) for historical data analysis.
3. **Select Chart Type**: Choose between a line chart or candlestick chart for visualization.
4. **Display Results**: The tool retrieves and displays stock data, sector information, industry details, and historical price movements.

### Portfolio Optimization
1. **Define Budget**: Users specify their investment budget.
2. **Desired Return**: Enter the target return percentage to balance risk and return.
3. **Optimization Results**: The system applies **Modern Portfolio Theory (MPT)** and **Knapsack optimization** to suggest optimal allocations with expected returns and risk metrics.

### Backtesting
1. **Select Stocks and Period**: Choose specific stocks for strategy testing.
2. **Apply Indicators**: Implement technical indicators (e.g., SMA, RSI) and analyze their effectiveness.
3. **View Results**: Get performance metrics including **Sharpe Ratio** to evaluate strategy performance.
